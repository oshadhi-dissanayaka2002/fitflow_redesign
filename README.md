# FitFlow Redesign

AI-powered fitness companion redesign – personalised workouts, private social circles, and camera-based nutrition tracking.

## Tech Stack
- Frontend: React Native + React Native Web
- Backend: Node.js / Express
- AI Service: Python / FastAPI / TensorFlow
- Database: PostgreSQL, Firebase Firestore
- Auth & Real-time: Firebase
